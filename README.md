Xem hướng dẫn cài đặt, vận hành, backup và kiểm thử tại [`artifacts/multi-tg-manager/README.md`](artifacts/multi-tg-manager/README.md) và [`artifacts/multi-tg-manager/OPERATIONS.md`](artifacts/multi-tg-manager/OPERATIONS.md).
